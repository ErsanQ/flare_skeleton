## 1.0.0

* Initial release
* FlareSkeleton — core shimmer widget with customizable size and shape
* FlareSkeleton.circle — circle variant for avatars
* FlareSkeletonTheme — adaptive light/dark theme support
* SkeletonListTile — pre-built list tile placeholder
* SkeletonCard — pre-built card placeholder with image
* SkeletonParagraph — pre-built text lines placeholder
* SkeletonGrid — pre-built grid of cards placeholder
* SkeletonLoader — animated switcher between skeleton and real content
* Zero dependencies
